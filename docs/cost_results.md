- Rule: a phase's cost is paid on entering the phase, whether it then succeeds or fails; Phase 2 always, Phase 3 only after passing Phase 2. Costs are not sampled; spending varies only with how far each drug gets.
- So the cost of N drugs takes only N+1 values: N × Phase 2 + K × Phase 3, K = number of drugs passing Phase 2. Quantiles are attainable values (inverted CDF).
- VaR95 = 95th percentile of cost (high cost is the bad tail, so VaR95 equals the 95th percentile); CVaR95 = mean cost in the worst 5% (Rockafellar–Uryasev definition, which handles the jumps of a discrete distribution).
- Expected trial cost per approved drug = expected cost ÷ expected approvals = (Phase 2 + P(pass Phase 2) × Phase 3) ÷ P(approval).
- **Probabilities and costs in the tables are analytic** (closed-form or exact discrete distribution); simulated values are used only for verification (section 5). Exception: approval within X years depends on durations, has no closed form, and is simulated.
- Timing settings: gap_months = 0, review_extra_months = 0 (ASSUMPTION defaults). Cost does not depend on p_priority (same seed, same gate outcomes).
