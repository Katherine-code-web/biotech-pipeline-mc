# 臨床試驗直接花費:BIO 與 Wong 並排

由 `scripts/run_costs.py` 產生,請勿手動編輯。

- 執行時間(UTC):2026-11-04T00:05:20+00:00
- 每格模擬 200,000 次;種子 20261028(每格 [seed, N, 情境索引],與 run_timed.py 相同);numpy 2.0.2
- 單位:**百萬美元(名目,2004–2012 混合年份)**。只計二期、三期的臨床試驗直接花費;送件與審查不計費用。
- 基準情境的階段成本(SOURCED,ASPE 2014 Table 2 加權平均,每個試驗):二期 13.35、三期 19.89。
- 乘數(ASSUMPTION 預設值):trials_per_phase = 1、overhead_multiplier = 1、cpi_factor = 1。
- 發生規則:進入一個階段就付該階段的成本(不論成功或失敗);二期必付,三期只在通過二期後才付。成本不做隨機抽樣,花費的變異只來自「每個藥物走到哪一關」。
- 因此 N 個藥物的花費只有 N+1 種可能值:N × 二期 + K × 三期,K = 通過二期的藥物數。分位數取實際可達的值(inverted CDF)。
- VaR95 = 花費的 95 分位(「壞」的一端是花費高,所以 VaR95 與 95 分位相同);CVaR95 = 最差 5% 情境的平均花費(Rockafellar–Uryasev 定義,處理離散分佈的跳點)。
- 每個核准藥物的預期試驗花費 = 預期花費 ÷ 預期核准數 = (二期 + 通過二期機率 × 三期)÷ 核准機率。
- **表中的機率與花費一律為解析值**(封閉公式或精確離散分佈);模擬值只用於驗證(第 5 節)。例外:「X 年內核准」與時程有關,沒有封閉解,為模擬值。
- 時程設定:gap_months = 6、review_extra_months = 0(ASSUMPTION 預設值)。花費與 p_priority 無關(同一種子下,關卡結果相同)。
