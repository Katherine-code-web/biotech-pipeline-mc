# Figure numbers

Generated by `scripts/make_figures.py` from `data/processed/*.csv` (written by `run_costs.py`).

**Rule:** probabilities and costs on the figures are analytic (closed-form) values. Probabilities of approval *within X years* depend on trial durations and have no closed form, so they are simulated (200,000 portfolios per cell). Other simulated values are shown here only to verify the analytic ones.

**Simulated cost per approval** = total cost summed over all simulated runs ÷ approvals summed over all runs (`total.sum() / n_approved.sum()` in `run_costs.py`). The previous code used `total.mean() / n_approved.mean()`; both means are over the same number of runs, so the two are algebraically identical. The code now uses the sum form and was rerun; the numbers did not change.
