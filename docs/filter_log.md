## Duration definition

- Duration = primary completion date − start date, in months (days / 30.4375).
- When CT.gov gives only `YYYY-MM`, day 15 is imputed (mid-month).
- This is **trial** duration, not **phase** duration.

## Outlier handling

Rows are **excluded** (not winsorized) and saved to `data/processed/durations_excluded.csv`. Rules are checked in this order; each row gets one reason.

| Rule | Reason |
|---|---|
| duration ≤ 0 months | Completion on/before start: data-entry error |
| 0 < duration < 1 month | Too short to represent a Phase 2/3 efficacy trial (mostly single-dose / PK-type studies) |
| duration > 180 months | Implausible for a single trial; usually a wrong date |
